本次更新完善进度记录管理，并优化项目状态选择。

- **记录重命名**：可在标题旁修改记录名称，保留正文和原有记录顺序。
- **删除单条记录**：确认后删除当前进度记录，保留其他记录及项目共用的图片。
- **记录时间**：标题下显示创建时间和最后修改时间，按本机时区精确到分钟。修改名称或正文后，自动更新修改时间。
- **状态选择优化**：重新设计 Doing / Done / Pending 下拉面板，显示状态色点、中文说明和选中标记，适配日间、夜间主题，支持键盘操作。

旧记录缺失的历史时间显示「未记录」，后续编辑会开始记录修改时间。

下载文件：

- Windows：`windows-x86_64.exe`，双击运行。
- Linux：`linux-x86_64.bin`，运行前执行 `chmod +x linux-x86_64.bin`。
- 源码：下载 **Source code (zip)**。

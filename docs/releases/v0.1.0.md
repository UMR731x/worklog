工作手记首次发布：启动后自动在浏览器打开，本地管理项目和每日进度。

- 项目状态、搜索与筛选。
- 按日期记录 Markdown 进度，支持预览、图片上传和粘贴。
- 自动保存与手动保存，可切换数据目录；读取目录内已有的项目记录。
- 数据使用本地 JSON 文件保存，每个项目独立存放。

### 下载与运行

- **Windows x86_64**：下载 `windows-x86_64.exe`，双击运行。
- **Linux x86_64**：下载 `linux-x86_64.bin`，执行：

```sh
chmod +x linux-x86_64.bin
./linux-x86_64.bin
```

- **源码 ZIP**：下载下方的 **Source code (zip)**。

首次运行默认在程序所在目录的 `data/` 中保存数据，也可以在设置中选择已有的数据目录。请将程序放在有写入权限的目录。

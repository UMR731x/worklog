本次更新加入主题切换、系统托盘和内置更新功能。

- **主题切换**：支持日间、夜间和跟随系统，选择自动保存，重启后保留。
- **全新图标**：更新页面、浏览器标签、系统托盘及 Windows 程序图标。
- **系统托盘**：关闭浏览器后，可通过托盘重新打开页面；右键选择「彻底退出」可关闭后台。
- **软件更新**：右下角新增更新入口，每天首次启动自动检查 GitHub Release，也支持手动检查。点击「下载并更新」后，自动下载对应版本、替换程序、重启并清理旧版，保留项目数据和设置。

下载文件：

- Windows：`windows-x86_64.exe`，双击运行。
- Linux：`linux-x86_64.bin`，运行前执行 `chmod +x linux-x86_64.bin`。
- 源码：下载 **Source code (zip)**。

从 **v0.1.0** 升级时，请先退出旧程序，再手动替换可执行文件，保留原有的数据目录和 `settings.json`。升级后即可使用内置更新功能。

Linux 托盘需要桌面支持 StatusNotifierItem / AppIndicator。
